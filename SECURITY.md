# Politique de sécurité

La Carte Tech est un site statique : pas de compte, pas de base de données, pas de données personnelles collectées.

## Signaler une faille

Si vous pensez avoir trouvé une faille (par exemple un script injecté dans une fiche, un lien malveillant ou une dépendance vulnérable), **ne la publiez pas dans une issue**. Utilisez plutôt le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.

Décrivez ce que vous avez vu et comment le reproduire. Vous aurez une réponse dès que possible.

## Erreur dans une fiche ?

Une information fausse ou périmée n’est pas une faille : ouvrez une issue « Signaler une erreur ».
