# Code de conduite

La Carte Tech est un projet ouvert à toutes et à tous, étudiants comme professionnels. Pour que chacun puisse contribuer sereinement :

- soyez bienveillant et respectueux, même en désaccord ;
- critiquez les contenus et les idées, jamais les personnes ;
- pas de harcèlement, d’insultes, de discrimination ni de propos haineux ;
- uniquement des informations publiques et sourcées : pas de données personnelles sur des particuliers, pas d’informations confidentielles ;
- acceptez qu’un contenu soit corrigé ou refusé s’il n’est pas sourcé.

Les comportements qui ne respectent pas ces règles pourront être supprimés (commentaires, issues, pull requests), et leurs auteurs bloqués.

Pour signaler un problème, ouvrez une [issue](https://github.com/eliotkoz-dev/la-carte-tech/issues) ou écrivez au mainteneur via son profil GitHub ([@eliotkoz-dev](https://github.com/eliotkoz-dev)).

Ce texte s’inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
